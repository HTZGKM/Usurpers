# 双份 · 餐厅前端原型

汉堡与披萨餐厅的课程原型，采用中文界面、休闲聚餐风格和桌面优先的响应式布局。此目录保留当前可点击版本，供小组讨论与持续修改。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

然后打开 <http://127.0.0.1:8765/>。

只需 Python 3 提供静态文件服务，无 npm 安装、构建步骤或后端依赖。图片、字体和图标脚本均保存在本地。

## 已有页面和交互

- 首页：聚餐摄影、菜品入口、到店环境和订座入口。
- 菜单：汉堡、披萨、小食、饮品，包含售完状态。
- 菜品定制：披萨尺寸、饼底和加料；汉堡酱料和加料；价格、数量联动。
- 购物车：增减、移除、修改口味、取消修改，以及选择堂食桌号后的模拟下单。
- 订座：日期、人数、时间、位置筛选、整桌选择、联系人校验及模拟确认。
- 交互反馈：桌面固定导航、局部过渡、抽屉开关、键盘焦点恢复及减少动效设置。

## 文件结构

```text
prototype/
  index.html        页面结构
  styles.css        设计变量、布局、响应式样式及 CSS 动效
  app.js            演示数据和交互状态
  assets/images/   摄影素材
  assets/fonts/    招牌字体及其许可证
  assets/vendor/   本地图标脚本及其许可证
  SOURCES.json     素材来源与授权链接
```

可以分别使用 `#home`、`#menu`、`#menu/pizza`、`#booking` 和 `#visit` 访问相应页面或区域。

## 演示边界

所有菜单价格、规格、桌位与供应状态都是模拟数据；最终业务规则仍需小组确定。订单和预订只存在当前页面内存中，刷新会重置，不向餐厅发送信息，不接入支付，不保存联系人。

当前点单方式为到店堂食，订座按整桌选择。尚未实现登录权限、工作人员或厨房页面；候选创新功能不等于本版承诺。

未来可将页面拆为 Flask/Jinja 模板并替换数据来源；此原型未引入 React 或其他前端框架。

## 字体、图片与图标

摄影为已列明来源的参考素材，不代表真实店铺或菜品。完整来源见 [SOURCES.json](SOURCES.json)，页面底部“关于本页”也保留了素材说明。

- 招牌字：站酷庆科黄油体，许可见 [OFL.txt](assets/fonts/OFL.txt)。
- 图标：Lucide 0.468.0，许可见 [LICENSE](assets/vendor/LICENSE)。
- 摄影：Unsplash 与 Pexels，分别遵循来源记录中的素材许可。

仓库许可证不替代上述第三方素材各自的许可。新增招牌标题汉字时，应更新字体子集；完整原字体同时保留在 `assets/fonts/restaurant-sign.ttf`。
